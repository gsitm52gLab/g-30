# G17 external AI server contract

This adds explicit OpenAI execution to G16. Synthetic demonstration remains available and never silently substitutes for the provider. G16/G15 original and reference authorization, immutable extraction, corpus, quote/citation validation, human review and G10/G11 contracts remain in force. This document describes implemented interfaces; live success and checkpoint acceptance require separate execution evidence.

- `POST /api/ai-review/inputs/:id/start`: existing `StartAnalysis`; `engine: provider` is additive. Same input/corpus/model/prompt/settings basis uses one logical run. New network attempts require the retry route. Current expectedRunId and idempotencyKey remain mandatory.
- `GET /api/ai-review/settings?contextId=...`: current GSG scope only. `{contextId,revision,enabled,configured,model,baseURL,keyPresent,issue,message,limits,priceCap:null,externalTransmission}`. No key or secret fragment. Default enabled means configured-and-not-disabled; enabled alone is not transfer permission.
- `POST /api/ai-review/settings`: contextId, enabled:boolean, expectedRevision, idempotencyKey. Current scope, CSRF, CAS and receipt. Returns settings plus ids:[settingId]. A change during an in-flight response prevents publication.
- `POST /api/ai-review/runs/:id/retry`: expectedRevision,idempotencyKey. Current exact source/role/corpus/settings, same logical run, maximum three explicit network attempts. Only timeout/429/provider5xx are transient. No background resend, SDK retry or remote exactly-once claim.
- Existing workspace adds providerSettings and provider engine option. Existing detail adds provider:{model,promptVersion,settingRevision,pricingVersion,attempts,retryable,remoteExactlyOnceGuaranteed:false}; synthetic history has provider:null. Attempts distinguish intent, observed fetch invocation, outcome, interrupted/unknown, input bytes and approximate byte-based token estimate, safe request/response IDs/hash, nullable provided usage/cost, schema/grounding status. Raw provider error bodies are never projected or logged.

Storage: mutable context setting; immutable run plan; monotonic per-network-attempt intent/dispatched/settled; immutable outcome; unchanged logical aiAnalysisRun/result. Run identity, model/prompt/corpus/input remain immutable. Same UoW claims admission, durable receipt, run and attempt; SQLite indexes provide cross-process uniqueness. Concurrency2, queue16, 6 actor/context attempts/minute,45s network,90s claim,3 attempts; 65536 input bytes,131072 serialized request bytes,3000 max output tokens. These are technical controls, no price gate.

Before each fetch, fresh G15 prepareTransfer verifies exact server-owned provenance and actual original bytes plus original AND reference ACL. Only approved extracted segments and curated official excerpts leave the server; whole files, unselected pages, contact details and arbitrary product data are excluded. After response, fresh current ACL/source/claim/corpus/settings are required before storing visible candidate. Safe usage/failure facts survive denied late output; candidate text is discarded.

A durable intent is not proof of transmission. Dispatched means the actual fetch promise was created, not server receipt/completion. A crash in the narrow pre/post fetch persistence window remains unknown. No automatic retry of interrupted unknown intent. Timeout has uncertain remote outcome and may be explicitly retried within the bound. A returned completed response, valid schema, checked source locations and sufficient grounding are separate facts.

Refusal, incomplete, parsing, missing key, disabled, authentication/permission,429,5xx, timeout, network and unknown outcome remain distinct.
