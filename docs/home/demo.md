# 발표 대본

GS HALE은 해외 헬스케어 진출에 필요한 모든 일을 하나의 흐름으로 연결해, 글로벌 헬스케어 시장에 새로운 물결을 만드는 플랫폼입니다

GSG 운영자는 국가·리테일러·브랜드 범위에서 담당자를 지정하고 업무와 기한을 요청합니다. 브랜드 홈에서 같은 요청과 필요한 자료를 보고 답변합니다. 다섯 질문 중 네 개만 답변했다면 남은 질문은 한 개로 표시됩니다. 상품정보는 독립 메뉴에서 등록·수정하며 업무의 관련 상품으로 연결됩니다. 전체 제출, 검토, 외부 전달과 GSG 수동 완료는 각각 별도 기록입니다.

홈의 조회 범위를 바꾸고 목록·칸반·프로젝트 타임라인에서 같은 담당·상태·상품·기한을 확인합니다. 일본 일반 화장품 문안의 약기법 사전검토는 최종 승인 판정이 아닙니다.
